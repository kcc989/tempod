# S20: Read-only controls for library runs

Status: real-login edit challenge remains open. No configured Claude, Codex, OpenCode or Pi login is available in this managed environment. Fake-adapter tests establish protocol behavior, not whether a real model can change files through its shell.

| Agent    | Implemented control                                        | Evidence and remaining gap                                                                                          |
| -------- | ---------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| Claude   | Select advertised `plan` mode                              | Existing adapter evidence advertises the mode; the edit challenge has not run.                                      |
| Codex    | Select advertised `read-only` mode                         | Select only if offered; otherwise report unsupported access. Real mode advertisement/edit challenge is open.        |
| OpenCode | Select advertised `plan` mode                              | Existing adapter evidence has no offered modes; report unsupported access when absent. Real edit challenge is open. |
| Pi       | Deny `write` and `edit` through the existing profile guard | Fake tests verify denied tools. Shell-based edits remain an unverified gap.                                         |

The implementation is in [session access](https://github.com/kcc989/tempod/blob/main/packages/tempod/src/acp/session.ts) and [run profiles](https://github.com/kcc989/tempod/blob/main/apps/tempo/src/do/workspace/queue.ts). Run each pinned adapter from [versions.json](https://github.com/kcc989/tempod/blob/main/container/versions.json) with a real login, request an edit through both a file tool and shell, and compare the tree. Record the offered mode IDs, model, timings, tree before/after and any unsupported field. A changed tree produces a warning and Revert; protected login/config changes fail the run.
