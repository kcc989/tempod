# S21: Role continuation and result files

Status: historical, superseded by [S23](https://github.com/kcc989/tempod/blob/main/spikes/S23.md). The result-file implementation and its tests have been removed. The following describes the prior contract; it is not current acceptance evidence. Real-login spike was not run. The implementation and local verification follow [tab 08](../docs/08%20Events%20and%20Agents.md), but the managed workspace has no authenticated agent sessions with which to establish its acceptance criteria.

The Worker tests in `apps/tempo/test/worker/roles.test.ts` verify that missing or invalid results queue a fixed follow-up prompt in the same session, that prompt does not repeat first-prompt instructions, results are bounded and validated, and a valid continuation completes the run. The daemon ACP tests verify reads/writes to `/home/tempo/roles/<runId>/result.json`, including rejection of paths outside allowed roots. These tests use a fake adapter and do not establish that a real model follows the instructions.

To complete S21, run each pinned agent (Claude, Codex, OpenCode and Pi) with a real login. Send a first prompt containing a unique fact, let it end with `end_turn`, then send a second prompt in that same session asking for the fact. Record the agent/model versions, session IDs and timings. Next request a read-only role with the fixed result instructions and verify a valid result in at most one continue. Record how often the agent changes workspace or protected login/config files. Any protected-file change fails the run, including credential refreshes; there is no exemption.

Deployed Gate H also remains open. It requires Gate B and three consecutive real-login runs covering the chain, role shadowing, access-violation revert, cyclic-role limits, timeout, container failure/restart and a credential grep of lifecycle events/results.
